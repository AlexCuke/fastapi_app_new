Структура бэкенда

Проект представляет собой асинхронный интеграционный сервис на FastAPI с веб-интерфейсом.

Основные таблицы БД

  • config — параметры подстановки (@config:key)
  • request_templates — шаблоны команд
  • status_tracker — история статусов
  • elastic_index — данные из Elasticsearch
  • index_final — итоговая таблица с выровненными колонками
  • sort_headers — отображаемые имена заголовков

Для работы фронтенда необходим запущенный бэкенд на http://localhost:8000 с включённым CORS.

Все API-эндпоинты описаны в /docs бэкенда.
